# Learning

Authentication identifies a principal; authorization limits that principal's actions.
Source content can describe an administrator without becoming one. Trusted configuration
and execution checks supply authority; a model verdict does not.

Detection misses and unauthorized effects are different measurements. Ten resource/tool
fixtures were content false negatives but the execution boundary denied their effects.
Conversely a multilingual instruction can corrupt an answer without any tool execution.

Benign quotation requires legitimate-task controls as well as threat examples. A blanket
keyword rule overblocks lessons. This implementation's trusted analysis-only profile has
no capabilities, but ordinary quote summaries still expose measured false positives.

The first encoded-canary test caught a minimum-token-length gap. Review later found that
an inspection needed exact action/session binding. Both have regression tests; removing
session binding deliberately made the suite fail, proving that particular test detects it.

Raw drafts are not verified work: local fixture generation failed acceptance and free
remote generation truncated. Preserve failures, review independently, and do not infer
real-model safety or allowance savings from these observations.

Evaluation inputs need the same boundary discipline as the defended route. ECC self-review
caught malformed fixture structures reaching the unprotected baseline and empty split
metrics. Validate before indexing/hashing; use null for unmeasured latency rather than
fabricating zero. CLI regression tests verify the actual structured failure response.

Optional exercise: explain why a well-formed, detector-ALLOW report save can still be
denied by a destination classification check, and why a valid human approval does not
change that permission. Then find the corresponding test and execution condition.
